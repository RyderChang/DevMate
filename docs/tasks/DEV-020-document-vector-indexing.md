前置：[DEV-019 证据](../testing/embedding-index-preflight-acceptance.md)、

## 目标与范围

将完整活动 `CHUNKED` 处理代投影为完整、版本化 `INDEXED` 代，具备身份隔离、幂等、资源控制、
短事务发布、删除交接、未知写入恢复和可观测状态。上传和处理均不自动触发索引；所有开关默认关闭。
仅支持固定本地 Qwen 规格，不同时开发云适配器；付费配置默认关闭且金额额度为零。
不实现检索/RAG、流式对话、前端、用户仓库代码执行或生产部署。

## 公开能力与受控模型进程

- knowledge 的索引 Application Service 使用项目公开服务及内部活动片段读取边界；归属校验先于幂等重放。
- ai 新增独立 Embedding 公开能力与 token 计数能力，冻结规范化输入、规格和操作标识；chat 能力保持独立。
- JDK HTTP 基础设施适配受控本地模型服务；计数与推理必须使用同一固定词表、修订、特殊标记和前缀。
- 模型进程只处理这些固定数据与已知实现，不加载远端自定义代码，不接收模型路径、下载 URL 或工具请求。
- CPU 使用冻结的显式因果/padding mask，验证相同输入与原生路径的数值等价性；
  资源隔离、进程终止及总截止时间可测试；服务在忙时返回受控错误，不隐式排队或加载第二模型。
- 启动核对指纹并运行冻结计数 fixture；目标 Linux 的依赖/wheel 或镜像 digest、许可证和全输入边界先核验。
- Stub 可完成日常 CI，但功能 PR 还须实际启动固定本地模型服务进行合成 HTTP 集成冒烟；不调用付费 API。

本任务必须实现完整模型服务与 JDK 合同，不能留下只有 Stub 能运行的占位适配器。
首版服务仅绑定 loopback；非 loopback 部署需先审查 TLS/认证及地址白名单。
建议 tokenize 总截止 10 秒、Embedding 300 秒、Qdrant 30 秒；超时与进程取消分别验证，
客户端超时本身不能清除未知远端操作记录。

## 数据和工作流程

使用新的 Flyway migration，禁止修改 V7 或任何已执行版本。索引工作、请求映射、批次与尝试、
点清单/批清单摘要、资源预留、向量操作、独立清理债务需要可追踪持久关系。
主键沿用 BIGINT；冻结 owner/project/document/processing/index/spec、块数量/ordinal/摘要和源 SHA。
文档维护明确活动索引代引用，状态展示区分最近尝试与仍有效旧代。
不能把 `INDEXED` 只做成原文件状态枚举而缺少完整活动代与恢复依据。

锁顺序沿用项目、文档、处理记录，随后索引记录、预算/容量行；全局额度行采用一致顺序。
远程计数、推理与 Qdrant 调用均在事务外；每次跨边界前后核对资格、操作版本与租约。

1. 短事务校验未删除项目/文档、活动完整处理代和固定规格；冻结清单，预留容量及请求映射。
2. 有界扫描器条件领取工作；事务外精确计数所有活动片段，不截断或暗中重新分块。
3. 单输入超过 6000、批次超过 4、合计 6000 或 padding 后总位置超过 6000、任一异常输入时整代明确失败，不静默丢块。
   空白块规则需明确为调用前整代受控失败，不能改变已有块编号。
4. 短事务原子预留本地 token 工作量，持久冻结批次/尝试；模型调用未知仍占用该尝试额度。
5. 模型回执全部通过 index/model/spec/数量/维度/float32/单位范数/usage 校验后，持久确定点定位和向量操作。
6. 事务外执行有界 upsert，成功/失败/UNKNOWN 都可在重启后找到全部预期点；重复 upsert 使用同一点 ID。
7. 所有批次均完整确认，并检查活动处理代、原 SHA、项目/文档资格、操作版本、块清单摘要和规格后，
   在同一短事务发布新活动索引代；失败不替换仍有效旧代。不能靠“点数量相同”证明来源正确。
8. 退役旧代持久清理；状态与审计只记录安全定位/用量/耗时，不记录片段正文、向量数组或原始 HTTP。

## 有界幂等、资源和费用

索引请求采用 UUID。建议继承 ADR 0005 的模式：创建活动代的原请求映射在活动期间保留，
其他绑定与清理后终态映射保留首次接受后的固定 24 小时，重放不续期。
提议每文档最多 100、每 owner/project 最多 10,000 条未清理索引映射；已过期但未清理及父文档已删除仍占额。
已有 UUID 合法重放先处理；满额拒绝新 UUID，不能新增失败映射绕过额度。

待接受的保守资源提议：每索引代最多 1,000,000 tokens，项目 UTC 日 2,000,000、全局 UTC 日 10,000,000。
每天的成功与 UNKNOWN 尝试均占用冻结日期额度；不能在午夜把重试当作免费。
模型实例只运行一个批次；单工作最多 3 次确定已终止的本地模型尝试，UNKNOWN 不自动重发。

向量容量以实际预计点数及 1024 维 float32 字节预留，元数据/索引开销另有配置余量，不能等同于物理磁盘保证。
提议 owner/project 最多 500,000 点 / 2 GiB 逻辑向量数据；全局最多 5,000,000 点 / 20 GiB。
暂存、活动、退役、UNKNOWN 预期点均计入额度，清理未完成不释放。另限制最多 4 个尚未清理代/文档。
独立 UNKNOWN/清理债务提议 owner/project 最多 10,000 条、全局 100,000 条，每条有界点清单/范围及字节，
批次最多 4 点；包括父资源已删除的记录。所有创建和预留必须在一致短事务原子检查，满额阻止新索引，
删除、已有重放与清理照常可执行。实际 schema、索引及容量默认值在实现 PR 验证，不能无界 JSON 存点集合。

不实现未经核验的付费供应商。将来收费必须单独确认价格有效期/币种/工作、项目日、全局日金额，
使用固定精度金额逐尝试原子预留；缺省均为 CNY 0，usage 异常或价格过期阻止后续发送。

## 删除、换代与 UNKNOWN

删除/项目软删除/处理换代与索引发布互斥，先清除活动资格并取消工作，再清理。
Qdrant payload 仅为十进制字符串归属和完整来源组合、ordinal 与规格；正文留在 MySQL 片段。
不同代的稳定 UUID 不覆盖；collection 固定规格，向量适配器强制归属过滤，不接受客户端过滤 JSON。

写入请求可能已发送且没有可证明的终止结论时保留 UNKNOWN；`wait=true` 超时或丢回执不能当作没写入。
恢复按冻结点清单和摘要核对，而非只凭数量；旧工作不得发布或补写 MySQL。
向量外部写入无法靠 MySQL fencing 阻止迟到，因此 UNKNOWN 操作定位与 tombstone 不设置自动清账 TTL。
先有独立、完整、持久清理交接才能删除片段/处理/父文档记录；不使用 FK 报错、内存事件或异常吞掉来代替交接。

每轮扫描、点检查与删除都有上限/截止/退避；重启继续。无法证明远端操作已经结束时，
保留债务、隔离资格、限制新增容量并转人工核对，不能在一次删除后查询不存在就释放。
人工清账必须先证明生产者停止和相关操作已结束，再删除、核对、审计；不可用人工按钮绕过证据。
未知写入不妨碍原文件删除，但其最小定位与容量必须由独立债务继承，不能随父记录级联丢失。

## API、文档与最小充分验收

只增加受 JWT/归属校验保护的索引触发 POST 和状态 GET；请求/响应不暴露正文、向量或内部服务 URL。
明确 PENDING/RUNNING/SUCCEEDED/FAILED/CANCELLED/UNKNOWN/CLEANUP_REQUIRED 等工作状态，与活动 INDEXED 资格分开。
API 路径、DTO、错误码、请求映射返回规则与具体状态转换在实现前冻结并同步 API 文档，不能边写边猜。

必须覆盖：

- 精确 fixture、6000/6001 边界、前缀/EOS/NFC、一致性握手失败、异常响应和总截止取消。
- 正常全量发布、重复请求/重放冻结、额度并发与满额重放、固定窗口、父资源删除后的额度占用。
- 部分模型/向量批失败、错误维度/NaN/float32 溢出/usage、向量数量相同但 ordinal/来源错误。
- MySQL 暂不可写、模型与向量响应丢失、已发请求后崩溃、重启、租约重领及旧操作版本拒绝。
- 删除/换代发生在计数、推理、upsert、最终发布各窗口；迟到向量写入、重复清理与债务交接。
- 真实固定 Qdrant/MySQL 的跨归属、完整来源组合、BIGINT 精度及 collection 不兼容检查。
- MockMvc 身份与归属、统一响应、默认关闭、无账户构建，以及既有 178 项后端与前端 CI 回归。

CI 使用合成 Stub，不依赖私人模型账户；真实本地服务集成结果另有可复现命令与运行时锁。
新增 migration 必须从空 MySQL 8 顺序执行；不能以 H2/Mock 证明恢复或 MySQL 兼容。
完成报告列出 commit、PR、实际命令/计数、剩余限制与回滚；功能回滚关闭索引写入和资格，
已存在清理债务仍需恢复处理，不能删表或改旧 migration 来回滚。

后续检索/RAG 另立任务，继承 ADR 0005 的 topK、资格刷新与有界补足。
