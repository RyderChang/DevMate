# DEV-025：真实项目资料的离线引用事实评估

日期：2026-10-09。状态：离线评估完成；真实 RAG 服务输出的质量评估待独立执行。

## 目标与范围

以 `develop` 的 DevMate 文档和实现为真实项目资料，逐条核对候选回答的事实断言是否得到所引来源支持，并识别规划与现状、历史与当前、来源资格与事实正确性的混淆。[评估记录](../testing/real-project-citation-fact-evaluation.md)固定基线、案例、证据、判定和限制。

本轮是离线人工核对。候选回答由评估者编写，包含刻意设置的误引和无依据问题，不是 DevMate RAG 或付费模型生成的回答。资料仅来自仓库；不上传真实项目文档、不启动模型、数据库或向量服务，也不评价检索召回率、线上回答准确率或生产表现。

## 验收口径

- 每个案例拆为可核查的单一断言，给出原候选引用及必要的校核来源；不能以“有引用”代替“引用支持断言”。
- 判定使用“支持”“反证”“资料冲突”“资料不足”；历史任务状态不能覆盖当前实现与较新的状态记录。
- 对找不到确定值的问题明确弃答；只在冻结的资料范围内陈述未找到，不把缺失证据推断为系统不存在。
- 记录实际执行的核对命令和基线 SHA。不得把人工构造案例的通过数量当作模型质量分数。

## 后续边界

后续若评估 DevMate 实际生成的答案，应另行确定受控资料集、模型环境、数据传输与费用边界，采集真实请求、回答和引用后，按本任务的逐断言口径评审。本任务不启用生产 RAG，不改变现有接口或配置，也不合并 [#42](https://github.com/RyderChang/DevMate/pull/42)。
