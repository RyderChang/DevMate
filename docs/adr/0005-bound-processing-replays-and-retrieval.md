# 0005：处理请求映射与向量检索的有界恢复

- 状态：Proposed
- 日期：2026-09-28
- 关联任务：[DEV-017](../tasks/DEV-017-document-processing-boundaries.md)
- 前置决策：[ADR 0004](0004-document-processing-and-index-boundaries.md)，当前仍为 Accepted。
- 接受后关系：继承 ADR 0004 的其他决策，替代其处理请求映射保留规则并补充检索资格与补足要求；接受时再将 ADR 0004 标为 Superseded 并添加互引。

## 背景

[PR #31 的请求映射审查](https://github.com/RyderChang/DevMate/pull/31#discussion_r4118625582)
指出：对已完成代提交任意新 UUID 都会新增长期映射，片段容量不能限制请求表增长。
[检索审查](https://github.com/RyderChang/DevMate/pull/31#discussion_r4118625579)
指出：仅按用户/项目查询 top-k，再由 MySQL 剔除退役向量，不能恢复被它们占据名额的有效结果。
现有 CI 通过不能证明这些设计缺口已关闭；需要将修订单独列为可确认决策。

## 建议决策

### 请求映射同时限制数量与保留时间

真正创建处理代的请求，在该代活动期间保留原始 UUID 映射；失败或退役清理后的最小终态映射保留 24 小时。
已完成同策略时的新 UUID 仍可绑定现有活动代并返回 200，但这种不创建新代的映射只保留首次接受后的 24 小时。
重放不续期；窗口外 UUID 可以按新的处理请求解释，窗口内仍冻结首次原 SHA 和策略，不因默认策略升级改变含义。

建议每文档最多 100 条处理请求映射，每用户/项目最多 10,000 条；
统计所有尚未物理清理的映射，包括在途、活动、失败、清理后终态及已过期但未被扫描器清理的记录。
该项目限制覆盖父文档已经删除但最小请求映射仍在保留窗口内的情况，防止循环上传/删除绕过每文档限制。

先校验身份、归属并处理已存在 UUID 的重放，再检查新映射额度。
额度检查与插入在同一短事务中原子执行，保证并发也不能超限。
额度不足对新 UUID 返回受控 409，不创建新的失败映射；已存在 UUID 的合法重放仍正常工作。
过期记录使用有界扫描物理清理后释放额度，不直接删除仍活动代的创建请求映射。
具体错误码、索引、额度行及 migration 在 DEV-017 实现 PR 审查。

### 先过滤当前资格，再校验与有界补足

未来检索先从 MySQL 取得当前用户/项目下、未删除且完整发布的活动处理代和索引代，
固定本次 Embedding 规格，并将这组有效来源组合加入服务端向量过滤。
当前原文件项目上限为 100 份，该资格集合有界；必须匹配完整组合，不能分别拼接文档 ID 与代 ID 列表造成交叉匹配。
userId/projectId 条件始终强制存在，客户端不能提供、删除或扩宽这些限制。

向量响应仍需再次核对 MySQL，防止资格读取后发生删除或换代。
剔除失效命中后不能直接把首次 top-k 的剩余量当作充分检索结果；若尚有候选，进行有界补足：

- 建议 `topK` 最多 20；每轮候选最多 100，整个请求最多检查 200 个不同向量点、最多查询 3 轮。
- 每轮刷新同一 Embedding 规格下的有效资格，排除已检查点；累积、去重、按得分和稳定点 ID 排序。
- 不跨不同模型/维度合并分数；新规格的查询向量不能复用旧规格生成结果。
- 满足 topK、当前资格下候选确认耗尽或达到预算即停止；分页/排除机制需在实际 Qdrant 适配器合同中验证。
- 达到预算仍未补齐时明确标注检索不完整，不能伪装为“知识库没有相关内容”，也不能为了补足取消归属过滤。

这些值是新建议，待确认后落实在检索任务；不加入 DEV-017 或提前创建检索 API。

## 后果与验证

请求映射不再由任意新 UUID 无界增长，代价是窗口外重放可以形成新请求，满额的新请求需要等待清理。
资格过滤减少退役点占位；二次校验仍保持删除安全，有界补足避免无上限扫描。
资格持续变化或预算耗尽时允许明确的不完整结果，不承诺并发换代期间总能补满 topK。

未来 DEV-017 测试须覆盖：100/10,000 边界、并发插入、满额重放、固定 24 小时窗口、
重放不续期、旧默认策略冻结、过期但未清理仍占额，以及删除文档后项目总额度仍受限。
未来检索测试须覆盖：大量退役点排在有效点之前、资格读后删除/换代、多轮去重、预算耗尽提示及跨归属隔离。
当前仅完成文档提议，没有执行这些业务测试。
