# 0009：RAG 字面标识符证据补位

- 日期：2026-10-11
- 关联：[DEV-033](../tasks/DEV-033-q4-evidence-selection.md)
- 继承：ADR 0005 的来源与预算边界、ADR 0008 的一次检索及最多五个来源合同。

## 原因与方案

冻结 Q4 的 E7 片段存在且合格，但同一 Cosine 查询中排名 19，原五个候选只覆盖 E8。核心结论正确不能替代 E7 的直接来源覆盖。采用 RAG 专用的 `rag-identifier-coverage-v1` 选择规则，不改变普通文档检索 API 的 Cosine topK。

在当前检索轮已取得且经 MySQL 资格与摘要核验的命中中，取 Cosine 降序、pointId 升序的前 20 个为选择窗口；最终五个仍按该顺序返回。问题中的独立 ASCII 大写标识符须为 3–64 字符，首字符大写，其余可为大写字母、数字或下划线，大小写敏感。无标识符或超过 8 个不同标识符时保持原五个。原五个已覆盖全部标识符时保持不变；否则按问题中首次出现顺序补入缺失标识符的最高分候选，替换最低分且不会丢失任何已覆盖标识符的候选，最多替换两个。不内置题号、CHUNKED、来源路径、SHA 或证据行；重复标识符或重复正文不增加权重。

只处理授权后的正文，不扩宽来源查询，也不追加检索/Embedding 请求或轮次。每轮 100 点、累计 200 点、3 轮，最终来源重校验及 RAG 发送/发布检查不变。提示词构建器继续执行五来源、8000 code points、5 KiB 快照及总输入上限，超限仍整片移除；补位不保证一定进入超限提示词。score 继续表示原 Cosine，不是新的混合分、语义支持或答案置信度。模板和模型参数不变，默认开关仍关闭。

## 取舍、验证与回滚

优点是无需新模型、索引或持久结构，能保留精确状态名的可检索片段。代价是可能替换一个语义相关候选；字面相同的片段未必直接回答问题，也可能含冲突或恶意文本。不得执行来源中的指令，或把字面匹配视为证据充分。

前 20 窗口外、没有字面标识符、超过两个缺失标识符或唯一覆盖无法保留的情况，不保证补齐。需要独立评估更广泛题集后才能作通用质量结论。当前只验证冻结十题的来源覆盖与边界，不授权真实模型、生产启用或自动合并。后续全题逐断言核验和输出约束采纳仍为独立任务。

回滚撤销本任务候选选择及文档，RAG 恢复原 Cosine 五候选；无需 migration、重建索引或改写历史结果。
